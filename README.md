## 3. Recent Cybersecurity Incident Analysis

### **Incident: GitHub OAuth Token & Secret Scanning Exploitation**
- **Overview:** Threat actors conducted targeted automated campaigns leveraging leaked continuous integration (CI) tokens and hardcoded API secrets found across public repositories to perform unauthorized supply-chain access and unauthorized repository modification.
- **Key Takeaways:**
  - Hardcoded secrets and exposed environment variables remain a top attack vector in software supply chains.
  - Automated scanning tools like GitGuardian and GitHub Secret Scanning are essential first lines of defense.
  - Implementing strict principle of least privilege (PoLP) and short-lived access tokens minimizes impact in case of token leakage.
